# Pelagic Oscillator K-17

An interactive mathematical creature living between a particle organism, a nonlinear-dynamics instrument, and a desktop toy.

Its 180-cell membrane is a continuously changing superformula. Every cell carries a slightly different natural frequency; Kuramoto coupling lets the population negotiate a common pulse. Membrane springs, traveling waves, stimulus pressure, energy, and shock memory turn those equations into visible behavior.

## Run

Open `index.html` in any current desktop browser. It is one self-contained HTML file: no build, server, packages, network, fonts, or media assets are required.

Optional deterministic URL:

```text
index.html?seed=104729
```

## Interact

- Move the pointer: the paired sensory organelles track it and the membrane becomes curious.
- Press and hold: feed the creature; it follows the stimulus and gains energy.
- Click: poke the membrane and watch the local impulse propagate.
- `Space`: trigger a whole-body defensive wave.
- `M`: mutate into a new deterministic morphology and palette.
- `R`: return to seed `104729`, generation `K-17.0`.
- `P`: pause/resume the scientific instrument.
- `S`: download a PNG specimen plate.
- `H`: hide/show the control panel.
- **Temperament** changes wave speed and shock persistence.
- **Coupling** changes oscillator synchronization and the live coherence trace.
